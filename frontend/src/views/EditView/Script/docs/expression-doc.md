# 表达式指南

AutoMas 表达式支持三种日志处理方案，分别是正则、函数和混合模式，用户可以基于熟悉的处理方案进行文档字段的提取，并允许将提取出来的字段进行拼接处理。

> 如果你了解 Excel 函数或者类代码的编写，我们推荐你使用函数。

> 如果你熟悉正则表达式的写法，我们推荐你使用正则。

> 如果你同时理解了以上两种写法，也可以使用混合模式进行编写。

---

## 函数

AutoMas 表达式内置了一些常用文本处理函数，你可以自由使用这些函数组成函数链进行处理。

以绝区零一条龙日志为例：

```
[23:48:19.773] [operation.py 675] [INFO]: 指令[ 咖啡店 ] 执行成功 返回状态 无需运行
[23:48:24.715] [operation.py 675] [INFO]: 指令[ 体力刷本 ] 执行成功 返回状态 剩余电量 187
[23:48:47.265] [operation.py 675] [INFO]: 指令[ 丽都城募 ] 执行成功 返回状态 大世界-普通
[23:48:58.475] [operation.py 675] [INFO]: 指令[ 丽都周纪 (领奖励) ] 执行成功 返回状态 大世界-普通
[23:49:20.635] [operation.py 675] [INFO]: 指令[ 情报板 ] 执行成功 返回状态 大世界-普通
[23:49:46.388] [operation.py 675] [INFO]: 指令[ 随便观 ] 执行成功 返回状态 大世界-普通
[23:49:52.855] [operation.py 675] [INFO]: 指令[ 通知 ] 执行成功 返回状态 成功
[23:49:52.914] [operation.py 675] [INFO]: 指令[ 一条龙 ] 执行成功 返回状态 全部结束
```

期望效果（如果你想同时采集失败的，同理再创建一条采集错误的规则即可，会一起推送的）：

```
✓ 咖啡店
✓ 体力刷本
✓ 丽都城募
✓ 丽都周纪 (领奖励)
✓ 情报板
✓ 随便观
✓ 通知
✓ 一条龙
```

我的函数表达式可以写作：

```
"✓ "+$().cutby("指令[ ",0,1).cutby(" ]",1,1)
```

该表达式各函数的作用效果如下（以第一条日志为例）：

| 函数                   | 处理结果                                                                              |
| ---------------------- | ------------------------------------------------------------------------------------- |
| `$()`                  | `[23:48:19.773] [operation.py 675] [INFO]: 指令[ 咖啡店 ] 执行成功 返回状态 无需运行` |
| `.cutby("指令[ ",0,1)` | `咖啡店 ] 执行成功 返回状态 无需运行`                                                 |
| `.cutby(" ]",1,1)`     | `咖啡店`                                                                              |
| `"✓ "+`                | `✓ 咖啡店`                                                                            |

其中 `$()` 表示获取整行数据（允许多次复用），再依次衔接 cutby 进行定位截断，最后用字面量 `"✓ "` 拼接到行首。

AutoMas 内置的函数如下：

### 截断函数 - cut

cut 函数用于删除文本中指定长度首或尾。

**用法：`.cut(num)`**

若 `num > 0`：切除开头 num 个字符

若 `num < 0`：切除结尾 |num| 个字符

**示例：**

| 原文                | 表达式             | 结果              |
| ------------------- | ------------------ | ----------------- |
| 请继续支持AutoMAS喵 | $().cut(3)         | 支持AutoMAS喵     |
| 请继续支持AutoMAS喵 | $().cut(-1)        | 请继续支持AutoMAS |
| 请继续支持AutoMAS喵 | $().cut(3).cut(-1) | 支持AutoMAS       |

### 保留函数 - get

get 函数用于保留文本中指定长度首或尾。

**用法：`.get(num)`**

若 `num > 0`：保留开头 num 个字符

若 `num < 0`：保留结尾 |num| 个字符

**示例：**

| 原文                | 表达式             | 结果       |
| ------------------- | ------------------ | ---------- |
| 请继续支持AutoMAS喵 | $().get(5)         | 请继续支持 |
| 请继续支持AutoMAS喵 | $().get(-8)        | AutoMAS喵  |
| 请继续支持AutoMAS喵 | $().get(5).get(-2) | 支持       |

### 定位截断函数 - cutby

cutby 函数用于删除文本自某段字符开始向前或者向后的文。

**用法：`.cutby("定位文本",0/1,0/1,序号)`**

定位文本用于确定切割起始位置。

第二个参数 direction：0 表示向前切割（去头），1 表示向后切割（去尾）。**默认 0**

第三个参数 keep：0 表示保留定位字符，1 表示不保留定位字符。**默认 0**

第四个参数 序号（nth）：定位文本的出现序号。正数表示第 n 次出现（1 起计数），负数表示倒数第 n 次出现（-1 即最后一次）。**默认 1**

> 可选参数均可省略，省略时按上述默认值处理。例如 `$().cutby("支持")` 等价于 `$().cutby("支持",0,0,1)`。

**示例：**

| 原文                                    | 表达式                               | 结果                        |
| --------------------------------------- | ------------------------------------ | --------------------------- |
| 请继续支持AutoMAS喵                     | $().cutby("支持",0,0)                | 支持AutoMAS喵               |
| 请继续支持AutoMAS喵                     | $().cutby("支持",0,1)                | AutoMAS喵                   |
| 请继续支持AutoMAS喵                     | $().cutby("AutoMAS",1,0)             | 请继续支持AutoMAS           |
| 请继续支持AutoMAS喵                     | $().cutby("AutoMAS",1,1)             | 请继续支持                  |
| 20:23 [体力刷本]完成[剩余体力:62] close | $().cutby(" ",0,1).cutby("]",1,0,-1) | [体力刷本]完成[剩余体力:62] |

> 最后一例中行内有两个 `]`，默认序号只认第一个（体力刷本后的），通过序号 -1 定位最后一个 `]` 才能保留完整内容。

> 若定位文本在行中找不到（或指定序号超出出现次数），函数会跳过处理、返回原文，不会报错。

### 提取函数 - sub

sub 函数用于提取文本两个位置里的子文本。（p.s：如果你愿意，用两个 `.cut` 也能实现同样效果）

**用法：`.sub(start,end)`**

start 表示提取的起始位置 num，从 1 开始。

end 表示提取的结束位置 num。

两个值均允许为负数，若为负数则倒数。

> 请注意 AutoMas 的函数的位置参数不同于编程语言的索引，第一个字符位置就是 1，而不是 0。

**示例：**

| 原文                | 表达式          | 结果                |
| ------------------- | --------------- | ------------------- |
| 请继续支持AutoMAS喵 | $().sub(4,-5)   | 支持Auto            |
| 请继续支持AutoMAS喵 | $().sub(-10,12) | 支持AutoMAS         |
| 请继续支持AutoMAS喵 | $().sub(1,-1)   | 请继续支持AutoMAS喵 |

### 定位提取函数 - subby

subby 函数用于提取文本中两个特定文本之间的子文本。

**用法：`.subby("首位文本","末位文本",0/1,0/1,首序号,末序号)`**

第三个参数 keepFirst：0 表示保留首位文本，1 表示删除首位文本。**默认 0**

第四个参数 keepLast：0 表示保留末位文本，1 表示删除末位文本。**默认 0**

第五个参数 首序号（nthFirst）：首位文本的出现序号。正数表示第 n 次（1 起计数），负数表示倒数第 n 次。**默认 1**

第六个参数 末序号（nthLast）：末位文本在首位文本之后的出现序号，-1 表示首位之后最后一个。**默认 1**

> 可选参数均可省略，省略时按上述默认值处理（即默认取首次出现并保留首尾定位文本）。

**示例：**

| 原文                                    | 表达式                      | 结果                        |
| --------------------------------------- | --------------------------- | --------------------------- |
| 请继续支持AutoMAS喵                     | $().subby("继续","MAS")     | 继续支持AutoMAS             |
| 请继续支持AutoMAS喵                     | $().subby("继续","MAS",1,1) | 支持Auto                    |
| 请继续支持AutoMAS喵                     | $().subby("继续","MAS",0,1) | 继续支持Auto                |
| 请继续支持AutoMAS喵                     | $().subby("继续","MAS",1,0) | 支持AutoMAS                 |
| 20:23 [体力刷本]完成[剩余体力:62] close | $().subby("[","]",0,0,1,-1) | [体力刷本]完成[剩余体力:62] |

> 最后一例中默认末序号只会匹配体力刷本后的第一个 `]`，通过末序号 -1 定位最后一个 `]`，才能提取完整片段。

> 若首位或末位文本在行中找不到（或指定序号超出出现次数），函数会跳过处理、返回原文，不会报错。

### 替换函数 - replace

replace 函数用于替换文本中的特定字符串。

**用法：`.replace("待替换文本","替换文本")`**

**示例：**

| 原文         | 表达式                          | 结果          |
| ------------ | ------------------------------- | ------------- |
| 白面鸮真可爱 | $().replace("白面鸮","AutoMAS") | AutoMAS真可爱 |

**进阶：逐行前缀**

当一个 `$()` 提取出多行结果时，字面量前缀只会加在第一行。用 `replace("\n","\n前缀")` 把每个换行替换成「换行+前缀」，再在开头补一个前缀，即可实现逐行添加前缀：

```
"⏸"+$('([^']+)').replace("\n","\n⏸")
```

| 原文                                        | 结果                                      |
| ------------------------------------------- | ----------------------------------------- |
| `列表 ['买信用商店', '刷体力', '活动奖励']` | `⏸买信用商店`<br>`⏸刷体力`<br>`⏸活动奖励` |

- `$()` 提取出多行（每行一个任务名，用 `\n` 连接）
- `.replace("\n","\n⏸")` 给第 2 行起每行加 `⏸`
- 开头的 `"⏸"+` 给第 1 行补上前缀

### 大小写转换函数 - upper/lower

upper 函数用于将文本中的英文全部替换为大写。

**用法：`.upper()`**

**示例：**

| 原文      | 表达式      | 结果      |
| --------- | ----------- | --------- |
| abc123def | $().upper() | ABC123DEF |

lower 函数用于将文本中的英文全部替换为小写。

**用法：`.lower()`**

**示例：**

| 原文      | 表达式      | 结果      |
| --------- | ----------- | --------- |
| Abc123DEF | $().lower() | abc123def |

> upper/lower 只影响英文字母，数字和中文保持不变。

### 去除空白函数 - trim

trim 函数用于去除文本首尾的空白字符（空格、制表符等）。

**用法：`.trim()`**

**示例：**

| 原文         | 表达式     | 结果   |
| ------------ | ---------- | ------ |
| `  咖啡店  ` | $().trim() | 咖啡店 |

> trim 只去除首尾空白，不会删除文本中间的空格。

## 正则

AutoMas 表达式中的正则与日志提取中的正则语法没有差异，你只需要在 `$()` 内编写正则就可以提取到想要的数据。同样以绝区零一条龙的数据为例：

```
[23:48:19.773] [operation.py 675] [INFO]: 指令[ 咖啡店 ] 执行成功 返回状态 无需运行
[23:48:24.715] [operation.py 675] [INFO]: 指令[ 体力刷本 ] 执行成功 返回状态 剩余电量 187
[23:48:47.265] [operation.py 675] [INFO]: 指令[ 丽都城募 ] 执行成功 返回状态 大世界-普通
[23:48:58.475] [operation.py 675] [INFO]: 指令[ 丽都周纪 (领奖励) ] 执行成功 返回状态 大世界-普通
[23:49:20.635] [operation.py 675] [INFO]: 指令[ 情报板 ] 执行成功 返回状态 大世界-普通
[23:49:46.388] [operation.py 675] [INFO]: 指令[ 随便观 ] 执行成功 返回状态 大世界-普通
[23:49:52.855] [operation.py 675] [INFO]: 指令[ 通知 ] 执行成功 返回状态 成功
[23:49:52.914] [operation.py 675] [INFO]: 指令[ 一条龙 ] 执行成功 返回状态 全部结束
```

期望效果：

```
✓ 咖啡店
✓ 体力刷本
✓ 丽都城募
✓ 丽都周纪 (领奖励)
✓ 情报板
✓ 随便观
✓ 通知
✓ 一条龙
```

那么正则表达式可以写作：

```
"✓ "+$(指令\[\s*(.+?)\s*\] 执行成功)
```

各步正则的处理效果（以第一条日志为例）：

| 步骤                           | 处理结果                                              |
| ------------------------------ | ----------------------------------------------------- |
| `指令\[\s*(.+?)\s*\] 执行成功` | 匹配到 `指令[ 咖啡店 ] 执行成功`，捕获组提取 `咖啡店` |
| `$(...)`                       | 取捕获组内容 `咖啡店`                                 |
| `"✓ "+`                        | 拼接前缀，得到 `✓ 咖啡店`                             |

其中 `$()` 存放正则表达式，正则中的 `()` 是捕获组，**只有捕获组里的内容才会被提取**。想提取整段匹配时，把整个正则包进一层括号即可，如 `$((指令\[\s*.+?\s*\] 执行成功))`。

详细的正则语法可以在文档顶部切换到「正则」文档进行查看。

## 混合模式

如果你已经阅读完函数和正则的语法，聪明的你应该就会直接理解什么是混合模式：即在 `$()` 内编写正则提取的同时，并衔接函数处理。这里我们举一个复杂例子。

以一条英文体力日志为例（这类日志常见于 ok 系英文输出的脚本）：

```
[12:30:45.123] [stamina.py 88] [INFO]: stamina: current 160 / max 240
```

该条日志为英文，但是我希望推送时为中文。我们就可以在使用正则提取到关键内容后，衔接 replace 函数替换其英文关键字，如下：

```
$((stamina:\s*current\s+\d+\s*/\s*max\s+\d+)).replace("stamina","体力").replace("current","当前").replace("max","上限")
```

各步处理效果：

| 步骤                                           | 处理结果                                  |
| ---------------------------------------------- | ----------------------------------------- |
| `((stamina:\s*current\s+\d+\s*/\s*max\s+\d+))` | 提取整段 `stamina: current 160 / max 240` |
| `.replace("stamina","体力")`                   | `体力: current 160 / max 240`             |
| `.replace("current","当前")`                   | `体力: 当前 160 / max 240`                |
| `.replace("max","上限")`                       | `体力: 当前 160 / 上限 240`               |

最终推送结果：`体力: 当前 160 / 上限 240`。

> 混合模式的精髓在于：**用正则负责「圈出字段」，用函数负责「改写字段」**。正则擅长的交给正则，函数擅长的交给函数，各司其职。

## 拼接

无论使用何种模式，表达式都支持多种结果的拼接，共有三种拼接方式：

### 字面量 - "文本"

用双引号包裹的文字会原样输出，常用于添加前缀、后缀或分隔符：

```
"✓ "
" -> "
"："
```

支持转义：`\"` 输出引号，`\\` 输出反斜杠，`\n` 输出换行，`\t` 输出制表符。

> `\n` 常配合 `replace` 实现「逐行前缀」，见下方 replace 函数的进阶用法。

### 同行拼接 - +

`+` 将左右两边的片段拼在同一行：

```
"✓ "+$(指令\[\s*(.+?)\s*\] 执行成功)
```

结果：`✓ 咖啡店`（前缀和提取结果在同一行）。

### 换行拼接 - ;

`;` 将左右两边的片段各占一行：

```
"✓ "+$(指令\[\s*(.+?)\s*\] 执行成功);"✗ "+$(指令\[\s*(.+?)\s*\] 执行失败)
```

成功和失败各占一行输出。

### 拼接规则

1. 顶层 `;` 将表达式分成多行，各行独立求值，行间以换行拼接
2. 顶层 `+` 将一行内的多个片段拼在一起，不换行
3. **一行内所有 `$()` 必须全部命中，该行才会输出**；任一未命中则整行跳过
4. `$()` 内的 `+`、`|`、`"` 属于正则本身，不会被当作运算符（`|` 在 `$()` 内是正则的「或」）
5. 提取表达式留空 → 返回原文

> `$()` 内的正则默认开启 `DOTALL` 模式，`.` 可以匹配换行。如果只想匹配一行内的内容，用 `[^\n]+` 代替 `.+`。

## 常见问题

### 裸文本不生效

提取表达式中，正则必须用 `$()` 包裹。以下写法**不会生效**：

```
指令[ 咖啡店 ] 执行成功       ✗ 裸文本，不会被识别
$(指令\[\s*(.+?)\s*\] 执行成功)  ✓ 正确
```

### 无捕获组没有输出

`$()` 内的正则若**没有捕获组**，只会匹配、不提取，返回空串，该行不会输出：

```
$(任务结束)           ✗ 无捕获组，返回 ""，无输出
$((任务结束))         ✓ 用捕获组包裹整段正则，提取 任务结束
$(指令执行: (\S+))    ✓ 用捕获组标记要提取的部分
```

### 函数与正则的边界

`$()` 内的所有内容都是正则，函数必须写在 `$()` 之外、用 `.` 衔接：

```
$(指令\[(.+?)\]).trim()        ✓ 函数在 $() 之外
$(指令\[(.+?)\].trim())        ✗ 函数被写进了正则里
```

### 正则跨行贪吃

`$()` 内的正则开启 `DOTALL`，`.` 会跨行。用 `[^\n]+` 限制在一行内：

```
$((邮件：.+))        ✗ 会吞掉后面的所有行
$((邮件：[^\n]+))    ✓ 只取邮件这一行
```

## 调试建议

1. 先用**匹配正则**过滤出你要的行，提取表达式留空，确认过滤正确
2. 再填**提取表达式**，用 `$()` 包住你想提取的部分
3. 用规则旁的 🐛 调试按钮粘贴日志行，即时验证结果
4. 如果提取结果多了/少了，检查 `+` 和 `*` 的贪婪问题，试试 `+?` 或 `*?`
